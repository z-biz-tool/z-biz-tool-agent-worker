## 三、测试夹具原则

- **隔离环境**：所有测试使用临时 HOME（`tempdir`），不触碰用户真实 `~/.z-agent-worker/`
- **不执行破坏性命令**：mock CLI 仅 echo 预设输出，不运行真实 shell
- **未测不声称通过**：当前仅 `agent_session.rs` 2 个测试 + `agent_proxy.rs` 1 个测试实际存在并通过；其余均为规划
- **CI 可重复**：GitHub Actions 中运行，无需本地 CLI 安装
