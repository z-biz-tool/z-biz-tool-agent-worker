## 二、交互优化方案

### 2.1 任务详情面板（替代纯 Modal）

**现状**：点击"查看输出"弹出 Modal（`App.tsx` L570-588），仅展示 pre 文本。

**方案**：右侧抽屉式详情面板，包含：
- Tab 1：任务信息（标题/描述/状态/分配/时间线）
- Tab 2：实时输出（流式 Markdown 渲染 + 代码高亮）
- Tab 3：消息对话（user/agent 消息流，支持追问）
- Tab 4：工具调用日志（结构化展示每次 tool_use）
- 底部操作栏：通过/驳回/中断/重试

### 2.2 执行中断按钮

**现状**：任务进入 doing 后无法停止。

**方案**：
- 前端：doing 状态任务显示"停止"按钮
- 后端：新增 `cancel_task` Tauri command → 向 agent-proxy 发送 cancel 信号 → proxy kill 子进程
- agent-proxy：新增 `POST /v1/session/:id/cancel` 端点

### 2.3 流式输出展示

**现状**：`agent_runner.rs` L49 使用 `"stream": false`，等全部完成才返回。

**方案**：
- agent_runner 改为 SSE 流式消费
- 通过 Tauri event (`app.emit("task-output", payload)`) 逐 token 推送到前端
- 前端使用 `listen("task-output")` 实时更新输出区域
- 打字机效果 + 自动滚动 + 代码块识别

### 2.4 危险操作审批弹窗

**现状**：Agent 执行无任何拦截。

**方案**：
- agent-proxy 解析 CLI 输出中的 tool_use 事件
- 识别到危险操作（shell exec / file delete / network request）时暂停执行
- 通过 SSE 特殊事件 `approval_required` 通知主应用
- 主应用弹出审批 Modal（展示操作详情 + 风险等级）
- 用户 Approve/Reject → 主应用回调 proxy → proxy 继续/终止

### 2.5 看板视图增强

**现状**：按状态分组的纵向列表（`App.tsx` L419-461）。

**方案**：
- 增加经典看板列视图（横向 5 列，卡片可拖拽）
- 父任务卡片可展开显示子任务进度条
- 卡片上显示：Agent 头像 + 执行时长 + 输出摘要前 2 行
- 支持按 Agent / 优先级 / 时间筛选

### 2.6 Agent 状态面板增强

**现状**：卡片显示 name/status/cli_type/model（`App.tsx` L132-198）。

**方案**：
- 增加 Agent 当前任务实时输出预览（最近 3 行）
- 增加 token 消耗统计（今日/本周）
- 增加 Agent 健康指示（proxy 连通性）
- 支持 Agent 能力标签（可执行的工具类型）

## 四、用户旅程优化（核心路径）

```
创建项目 → 引入本地 Agent → 创建任务 → 分配 Agent
    → [审批危险操作] → 实时查看输出 → 任务完成
    → 验收（通过/驳回） → 驳回则补充说明重执行
```

**当前断点**：
1. "引入本地 Agent" 依赖 agent-proxy 在线，但无明确状态指示
2. "分配 Agent" 后立即进入 doing，无确认步骤
3. 执行过程完全黑盒（无输出、无进度、无中断）
4. 验收时只能看到最终 output 纯文本，无结构化展示

**优化后**：
1. 顶部状态栏显示 proxy 连接状态（绿/红点）
2. 分配前弹出确认（展示 Agent 信息 + 任务摘要 + 预估风险）
3. 执行中实时流式输出 + 工具调用卡片 + 中断按钮
4. 验收面板：Markdown 渲染 + 文件变更 diff + 逐项通过/驳回
