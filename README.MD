# z-cc-worker 

## 背景

当前是一个可以打出npm的一个项目。这个npm包的功能是：

1. 启动之后会出现一个页面
2. 页面之中会有多各纵向的管理条，类似于teambition，管理条中是很多任务，任务可以在管理条中拖动。
3. 拖动表达当前的任务状态变更
4. 第一个管理条是人的管理条
5. 第一个管理条内的人的概念是启动本地的一个terminal，里面是claude code实例
6. 任何人的实例，都可以感知当前暂未结束的任务的列表，然后主动进入到这个任务进行执行

## 目标

1. 可以给与多个任务，用户只需要管理任务
2. 可以启动多个agent帮助消费我的任务
3. 任何任务都知道是哪个agent在干活，干活的状态是什么样的
